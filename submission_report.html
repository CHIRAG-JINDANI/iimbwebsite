Key Improvements Made

  • Centralized CSS Architecture: Replaced inline styling with a dedicated external stylesheet (style.css). Design tokens—including deep obsidian black (#070709), rich burgundy maroon (#851224), crimson accents (#d82b42), spacing scales, and radii—are organized into CSS custom variables (:root) for unified maintainability.
  • Minimalist Typography System: Standardized on Plus Jakarta Sans across all headings, body text, typewriter elements, and badges. Eliminates quirky, distracting fonts in favor of clean geometric letterforms, calibrated line heights (1.65), and negative tracking (-0.03em) for a sleek executive aesthetic.
  • Zero-Latency Navigation & Scrollspy: Optimized navigation clicks to trigger immediate 60fps smooth scrolling with 0ms delay. Active section tracking is driven by browser-native IntersectionObserver, completely eliminating layout-thrashing scroll event listeners.
  • Non-Intrusive Call-to-Action: Resolved desktop mail client latency by redirecting the header "Let's Connect" button to smoothly scroll to the #contact card, where visitors can copy verified contact details with a single click.
  • Cropped Editorial Portrait Stage: Reconfigured the profile composition to an executive 4:5 ratio, using object-position: center 54% and transform: scale(2.05) to bring direct focus to the headshot rather than distant background scenery.

User Experience & Interactive Polish

  • Dual-Theme Switcher: Provides native Dark Maroon and Crimson Light modes. The selected theme toggles the root [data-theme] attribute and persists across sessions via localStorage.
  • Interactive Skills Filtering: Filter tabs (All, AI & DS, Software & Web, Business & Creative) use vanilla JavaScript DOM methods (classList, style.display) for instantaneous visual sorting.
  • One-Click Clipboard API: Integrated on email and phone rows in the contact card, featuring a 2-second visual "Copied!" confirmation badge and automatic state restoration.
  • Throttled Back-to-Top Control: Employs requestAnimationFrame to toggle floating button visibility after 400px scroll depth, executing smooth window scrolling to top on click.
