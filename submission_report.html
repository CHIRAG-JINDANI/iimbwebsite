4. Design Decisions & Visual Philosophy

A. Color Theory & Mood (Dark Maroon & Black): Grounded in Module 2.4 (Color Theory), the website adopts an obsidian black background (#070709) paired with rich Burgundy Maroon (#851224) and vibrant Crimson highlights (#d82b42). This palette delivers high contrast readability, projects technical sophistication, and embodies intense focus suitable for AI and data science roles.

B. Minimalist Typography: Built using Plus Jakarta Sans for a unified, modern, and uncluttered reading experience. All quirky display fonts and monospace typewriter distractions were removed in favor of clean geometric weights, subtle letter-spacing, and calibrated line heights.

C. Responsive Media Queries: Built with a mobile-first philosophy using CSS Flexbox and Grid. Key breakpoints at 1024px (desktop to tablet) and 768px (tablet to mobile) handle dynamic reflowing of the hero grid, sidebar cards, and navigation drawer seamlessly.
