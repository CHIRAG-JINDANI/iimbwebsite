Introduction

The objective of this midterm assignment was to enhance the resume website built during the HTML module by applying CSS styling, layout techniques, typography, and responsive design. The website reflects my dual academic background—pursuing a B.Tech in Artificial Intelligence & Data Science at Gati Shakti Vishwavidyalaya alongside a BBA in Digital Business & Entrepreneurship at IIM Bangalore. My goal was to create a clean, modern, and professional resume website that clearly presents my technical internships, projects, skills, and creative interests.

Improvements made

  • Separate stylesheet: Moved all CSS rules into an external file (style.css) and linked it in index.html. Colors, fonts, and spacing are defined as CSS variables at the top of the file so they can be managed in one place.
  • Clean typography: Used Plus Jakarta Sans for headings, body copy, and UI labels. It keeps the text sharp, readable, and consistent across every section of the website.
  • Dark maroon color theme: Built around an obsidian black background with maroon red as the main theme and subtle crimson accents for buttons, borders, and badges. Included a dark/light mode toggle with preference saved in the browser.

Improvements made (continued)

  • Sticky navigation bar: Stays visible at the top of the page while scrolling using position: sticky and flexbox. Links jump smoothly to sections with zero lag. On mobile screens, it automatically turns into a hamburger menu.
  • Responsive layout: Used CSS Grid for cards and Flexbox for buttons and alignment. Tested with media queries so the page reflows into a single column on tablets and mobile phones.
  • Fast interactions: Added a dynamic typewriter effect in the hero section, one-click copy buttons for email and phone with instant feedback, and a back-to-top button that appears after scrolling down.

CSS concepts used

  • Selectors: Element selectors for global styling (body, h1–h4, p, a, button), class selectors for components like cards and buttons, ID selectors for section links (#about, #experience, #projects, #contact), and attribute selectors for the theme switcher ([data-theme="dark"]).
  • Display and position: display: flex for the navigation bar, buttons, and metrics ribbon. display: grid for the hero layout, about grid, and skills cards. position: sticky for the header, position: fixed for the back-to-top button, and position: relative/absolute for the badges on the photo stage.
  • Box model and spacing: Standardized margin, padding, border-radius, and border properties across cards. Used CSS variables to keep spacing consistent across the site.
  • Transitions and animations: Smooth hover effects on buttons and cards, a rotating dashed ring behind the photo, and subtle keyframe animations for the background glow.
  • Media queries: Breakpoints at 1024px and 768px to ensure the layout, fonts, and navigation adjust cleanly on mobile, tablet, and desktop screens.

Design decisions

I wanted the website to feel professional and technical, while remaining personal and easy to navigate. I chose a dark background with maroon red accents because it looks focused and matches the technical nature of AI and data science. Instead of using unusual or complex fonts, I selected Plus Jakarta Sans for its clean, geometric lines and high readability.

For the layout, each section is separated clearly with simple cards and borders so recruiters and visitors can scan information quickly without unnecessary clutter. Cards are used for grouping skills, internships, and creative work, while key achievements are highlighted using numbers and short tags.

Conclusion

This assignment helped me apply semantic HTML, CSS layout systems (Grid and Flexbox), positioning, and responsive design in a real project. Moving from basic HTML to a fully styled and hosted website showed me how thoughtful design choices, clear spacing, and clean code make a resume both functional and engaging. The final website is deployed on GitHub Pages and tested across desktop and mobile devices.
